# DuoDesk 日本語化プロジェクト（非公式）

元のプロジェクト：[0xCodez/DuoDesk](https://github.com/0xCodez/DuoDesk)  
本Fork：[r-fallingstar/DuoDesk_JP](https://github.com/r-fallingstar/DuoDesk_JP)

## 現在の対応状況

- 対象：**DuoDesk v2.5.0**
- **Windows / macOS / Linux のデスクトップ画面**：日本語表示に対応するための初期実装です。通常モードと複数端末（Mesh）モードの両方を対象にしています。
- 画面のメニュー・基本操作・接続・画面共有・アプリ・マウス・キーボード・クリップボード・通話・メッセージ・ファイル共有・設定と、機能アイコンのポップアップなどを翻訳しています。
- **Android アプリ、システムトレイの一部、OS固有のネイティブ表示、未登録のメッセージはまだ英語**です。完全翻訳版ではありません。
- まだ実機での総合動作確認やインストーラーの署名は行っていません。

## 言語の切り替え

デスクトップアプリの **「一般（General）」→「表示言語 / Language」** から言語を変更できます。上部の小さな切り替えボタンは削除しました。

- 初期状態は **日本語** です。
- 設定で **日本語** または **English** を選択できます。
- 同じ画面からいつでも言語を戻せます。
- 選択した言語は、同じアプリ環境で次回起動時にも維持されます。

元の機能に影響を与えにくいよう、画面のテキスト表示だけを置き換えています。内部プロトコル、設定値、接続先の識別子、ファイル名、デバイス名などは翻訳対象にしていません。機能側で英語の画面ラベルを参照している箇所は、元の表記を取得するように調整しています。

## Windows用インストーラーの作成方法

GitHubにログインした状態で、リポジトリの **Actions → Build Windows → Run workflow** を開きます。Fork直後はActionsが無効な場合があります。Actionsのページに「I understand my workflows, go ahead and enable them」などの確認が表示された場合は、内容を確認して有効化してください。

1. ワークフローの入力欄 **ref** に **i18n/japanese-desktop-v2.5.0** を指定します。
2. **tag** は空欄のまま実行します（リリースを新規公開せず、Actionsの成果物として作成するため）。
3. ビルドに成功したら、該当する実行結果の **Artifacts** から **duodesk-windows-x64**（一般的なWindows PC用）または **duodesk-windows-arm64**（ARM版Windows用）をダウンロードします。

> この手順は既存のビルドワークフローを利用するものです。日本語版のビルド成功・動作確認は現時点では未検証です。コード署名されていないアプリにはWindows SmartScreenの確認が表示される場合があります。

## 開発者向け

- 翻訳辞書と画面更新への追従：[shared/i18n-ja.js](shared/i18n-ja.js)
- 日本語フォント・言語設定のスタイル：[shared/i18n-ja.css](shared/i18n-ja.css)
- デスクトップ用HTML 6ファイルの最後で読み込んでいます。
- 未訳語を追加する場合は辞書に **画面上の英語表記と一致する文字列** を追加してください。
- 開発中は node --check shared/i18n-ja.js でJavaScript構文を確認できます。node --test shared/test/i18n-ja.test.js で簡易テストを実行できます。
